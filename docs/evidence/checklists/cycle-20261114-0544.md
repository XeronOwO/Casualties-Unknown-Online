# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.
- [x] Design comprehension — the `bodies` branch fails to compile, and a fresh client fails the same way, so the cache theory was wrong — evidence: the fresh pair at 05:43 answered `returned no value`; HEAD's file on that client answered `cloneCount 0`
- [x] Native parity — no game content; the probe file is back at HEAD — evidence: `git status` shows only the ticket line
- [x] Native parity probe — the fresh-client call is the evidence — evidence: the 05:43 `driver-error` and the 05:44 `ok`
- [x] Entry mapping — one entry, the driver's recipe action — evidence: `drive-in-process.ps1 -Action recipe`
- [x] Mechanism inventory — the failure is the branch's source, not a cache — evidence: the same-file comparison on one client
- [x] Whole-family audit — the earlier `typeof(Body)` failure had the same signature; the next attempt isolates the construct in its own recipe — evidence: the ticket's next-step line
- [x] Self-check table — tree reverted; only the ticket changed — evidence: `git status --porcelain`
- [x] Verification design — the bisect recipe names one construct at a time — evidence: the ticket line
- [x] Plan approved by the user — the goal's main line: the suite carries the regression — evidence: the goal's 2026-11-14 paragraph
- [x] Structure review done — a corrected reading; the probe stays at HEAD — evidence: the revert
- [x] Build + dotnet format + dotnet test normative gates pass — no code change this cycle — evidence: the 05:35 run

- [ ] Release-cycle deployment/acceptance: nothing deployed this cycle

- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
