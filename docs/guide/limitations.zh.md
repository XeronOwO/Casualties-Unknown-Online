# 限制

[English](limitations.md) | 中文

CUO 正在积极开发中,尚未发布。有些内容是有意不做的,有些是已知的粗糙之处。本页如实列出这份清单,
免得有人靠在一局里翻车才发现边界在哪里。

这个模组围绕共享世界而不是共享屏幕构建:每个人都在主机的世界里游玩,有自己的角色、自己的随身物品,
以及自己的视角。

## 有意不做的

- 没有主机迁移:主机退出,会话就结束。
- 没有专用服务器;会话永远运行在某个玩家的游戏里。
- 模组不会自动下载 —— 每个人自己安装同一批模组。
- 没有通用物理同步、没有对其他玩家的客户端预测,也没有反作弊。
- 游戏本身不支持多人,所以未来的游戏更新可能让适配器的一部分失效,直到它被更新。

## 已知的粗糙之处

- 不影响玩法表现的细节(部分音效、粒子与动画时机)在两台机器之间可能不同。
- 允许加入已经在运行的世界,但双方必须运行同一个构建。
- 游戏内的中文文本搜索需要与本仓库中 CUO 一同提供的拼音搜索插件。

## 细节在哪里

「哪些机制同步、哪些不同步」的技术清单属于参考层:`docs/features/` 下的功能矩阵,以及
`docs/backlog/README.md` 中记录的待办工作。
