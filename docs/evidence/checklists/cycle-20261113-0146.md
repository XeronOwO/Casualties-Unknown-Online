# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.

- [x] Design comprehension — the host's log proves the chain on the host's side; the member's own trace is the gap — evidence: the three `[HealReset]` lines.
- [x] Native parity — no native behaviour changed — evidence: docs-only cycle.
- [x] Native parity probe — the host log is the probe — evidence: `stored … through the authority path` and `applied the reset`.
- [x] Entry mapping — the entry is the console verb `/heal @a` — evidence: the console answer.
- [x] Mechanism inventory — the applied handler, the store and the member's own body are named — evidence: the ticket's new section.
- [x] Whole-family audit — the host's chain and the member's missing trace are both recorded — evidence: the ticket's two sections.
- [x] Self-check table — both logs are quoted — evidence: `## The host's own log`.
- [x] Verification design — the case records the member's log tail beside the reading — evidence: the ticket's last paragraph.
- [x] Plan approved by the user — night mode: the next probe is named, no product decision — evidence: the ticket's status.
- [x] Structure review done — the probe uses the existing `log-tail` action — evidence: the ticket names it.
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: gates 834/0 this cycle.

- [ ] Release-cycle deployment/acceptance: run by the agent after the commit
      (build → deploy → two-client acceptance per `docs/acceptance/`), outside the
      development commit gate; simulation/static evidence is the feature development
      verification standard.
- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
