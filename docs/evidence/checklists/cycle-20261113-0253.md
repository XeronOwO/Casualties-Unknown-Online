# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.

- [x] Design comprehension — the lock's completion needs the game's own `handStarted` while the button is held — evidence: the live reading.

- [x] Self-check table — the report's own `aim`/`live`/`progress` lines — evidence: `.acceptance/suite/report.md`.
- [x] Verification design — read the aim's `correctAngle` against the hand's angle next — evidence: the ticket bullet.
- [x] Plan approved by the user — night mode: a park with its cause, no product decision — evidence: the ticket bullet.
- [x] Structure review done — the case stays beside the others, switched off by one comment — evidence: `Suite.cs`.
