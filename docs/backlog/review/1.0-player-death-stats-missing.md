# Nobody counts a player's deaths

The run records what happened to enemies and items, but not how many times a player died. A host
running a permadeath or revive session has no reading of who died how often; the console and the
Admin page cannot answer the question.

## Design

The observability surface (`docs/design/cross-cutting/observability.md`) and the run's own state
(`docs/design/game/console-and-save.md` — what the run keeps across a cut). A death counter is a
per-player durable fact like the skills already carried by the character snapshot
(`docs/design/cross-cutting/saves-and-recovery.md`).

## The reading (2026-11-14, release build)

`grep 'TrackDeaths|DeathCount' src/` finds nothing; the respawn path logs a revive
(`[Respawn] revived …`) but keeps no per-player count. The reference mod ships `TrackPlayerDeaths` as
a host rule.

## Acceptance rows

1. Two deaths and a revive read a count of two for that player, from the host's own answer and from
   the member's.
2. The count survives a save/continue (it is part of the character's own facts).
3. A new character starts at zero.
