# Decisions by domain

The decision register (`../decisions/`) is numbered, not grouped. This page groups it by the area a reader arrives from,
so a page in this corpus can be followed by the rulings behind it. Numbers only: the text of a decision lives in the
register, and this page never restates it.

| Domain | Decisions |
|---|---|
| Authority, prediction and reports | 154 (authority kinds), 155 (carry invariant), 156 (ownership and death preservation), 157 (no prediction), 161 (accept-first only for what the host can represent), 265 (data validation, never behaviour validation) |
| Judgement and host rules | 184 (the affected side judges), 263 (a host rule reaches its readers and checks by interception) |
| Saves, cuts and recovery | 162 (save identity), 163 (repair-mode restore), 164 (multi-world repository), 165 (independent of the native save), 166 (v1 save scope), 167 (cut arming), 168 (in-flight classes), 169 (run values by owner and seam), 170 (a continue hands the local character to the client that can apply it), 171 (native character fields), 172 (restored world facts by role), 173 (a restored row's reach) |
| Layers and world facts | 174 (the layer boundary is one family), 175 (a trap row's verdict is its trigger patch), 176 (the menu-return trigger is the leave action) |
| Console and commands | 228 (the `/` overlay is the only command surface), 264 (the item-data language), 269 (`/gamerule`'s shape) |
| Console surface and CUO UI | 230 (CUO's input guard never blocks CUO's own surface), 232 (the world overlays are labels on the canvas) |
| Protocol and compatibility | 241 (pre-release baseline, per-change bump afterwards) |
| Item entries | 246 (the entry, not the item, decides the family) |
| Player state | 152 (durable skills are kernel-owned), 153 (kernel identity ensured when a member's entity sync starts) |
| Sleep and body state | 160 (normal and forced sleep are ordinary sleep) |
| Search and modding | 200 (pinyin search reaches the console through a pluggable stage), 205 (where a system lives), 210 (the Application layer) |
