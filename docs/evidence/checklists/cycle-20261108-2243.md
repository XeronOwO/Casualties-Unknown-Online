# Delivery Checklist

Every development cycle runs through this checklist, validated by `tools/check-delivery.ps1` before the cycle's commit.
The script refuses a commit while a required box is unchecked or carries no evidence, archives the cycle's record under
`docs/evidence/checklists/`, and resets every box. A box is checked only after the item was CONFIRMED done in this cycle:
the suffix records an observation. Documentation-only cycles fill every box in one pass and may skip `dotnet format`;
the focused normative-gate run is not optional. Deployment and multiplayer acceptance run after the commit.

- [x] Design comprehension — before the first code edit the ticket states, in its own section, the surface being changed — evidence: the code cycle's ticket sections (this is the record-only cycle for that change); the live reading is `docs/evidence/acceptance/save-backups-overwhelm-the-archive-20261108.md`.
- [x] Native parity — the three lines (player's action and expectation / the native chain the game itself runs / how the clone reproduces it) — `docs/development/native-parity.md` — evidence: n/a, a window surface.
- [x] Native parity probe — for a behaviour that mirrors a native action, the SAME action was run locally and across clients — evidence: n/a.
- [x] Entry mapping (a scope that crosses players or mirrors a native action only): the entry is every control of the CUO window — evidence: the Worlds page's controls were driven through the driver (`open-window`, `goto-page -Page worlds`).
- [x] Mechanism inventory: every touched mechanism has evidence (decompiled file:line or runtime log) or is explicitly marked unverified — evidence: the retention chain (`SaveOptions.BackupRetentionCount`, `PluginDependencyRegistrar.cs:160`, `WorldRepository.PruneBackups`) and the 10-files-per-world measurement are in the ticket and the evidence file.
- [x] Whole-family audit: fixing one mechanism, the whole family was aligned one by one (no piecemeal fixes — the turret-fire/geyser lesson) — evidence: the only retention consumer is `WorldRepository.PruneBackups`; the page reads the option through `IWorldLibrary.BackupRetention`.
- [x] Self-check table: mechanism x change x evidence, every cell filled — evidence: the three cells (empty rows, ceiling line, library getter) each name their code and their reading.
- [x] Verification design: how the runtime proves it (diagnostic traces, peer log comparison, hotrepl assertions) is decided — evidence: the deployed build `0.1.0+c84087ff` read through the driver and a frame; gates 831/0 on this tree.
- [x] Plan approved by the user (before deployment; investigation excepted) — evidence: the user's directive (2026-11-08, translated: "continue, finish it in one go").
- [x] Structure review done (touched classes <= 600 lines OR the size is recorded in docs/architecture-debt.json with its split plan; state bools; dead mechanisms deleted in the same round) — evidence: `OnlineUiWorldsDrawer.cs` 308 lines; no state bools added; no dead mechanism left.
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: build 0 errors; gates `passed! (0 failed, 831 passed)`; suite `passed! (0 failed, 6632 passed, net48)`; `dotnet format` exit 0.
