# 从这里开始

入门线:按顺序读,每一篇结束时你都能看到实际跑起来的东西。不要求你先懂 CUO,也不要求懂游戏内部。

1. [CUO 是什么](what-is-cuo.md) —— 这个模组做什么、一次会话长什么样、它有意不做什么。
2. [装起来玩](install-and-play.md) —— 安装、开一次会话、加入别人的会话,以及最常见的三种失败。
3. [搭好开发环境](set-up-dev-environment.md) —— 拿到仓库、构建、跑测试,并部署进自己的游戏。
4. [你的第一个模组](your-first-mod.md) —— 一个 CUO 模组需要哪两个文件、框架交给你什么、怎么看着它跑起来。

深浅分界:这条线只讲到"能用起来"。每个机制是怎么做的在 `../internals/`,精确的契约在 `../reference/`。
