# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.
- [x] Design comprehension — the recipe channel caches a failed compile per recipe name, so one bad edit poisons every mode — evidence: both modes answered `returned no value` after the `typeof(Body)` edit; the untouched branch included
- [x] Native parity — no game content touched this cycle; the recipe was reverted — evidence: `git status` shows only the ticket line
- [x] Native parity probe — the failing calls' own answers are the evidence — evidence: the two `driver-error` answers at 05:40
- [x] Entry mapping — one entry, the driver's recipe action — evidence: `drive-in-process.ps1 -Action recipe`
- [x] Mechanism inventory — one mechanism: a per-name compiled-recipe cache in the client, invalidated only by a restart — evidence: the answers before and after the edit
- [x] Whole-family audit — the earlier `select-character` "no value" had the same shape (an edit the channel could not take) — evidence: the ticket's earlier note
- [x] Self-check table — tree reverted, only the ticket line changed — evidence: `git status --porcelain`
- [x] Verification design — the next attempt restarts the host after the edit, then calls the recipe once — evidence: the ticket's next-step line
- [x] Plan approved by the user — the goal's main line: the suite carries the regression — evidence: the goal's 2026-11-14 paragraph
- [x] Structure review done — a reading, not a fix — evidence: the ticket line
- [x] Build + dotnet format + dotnet test normative gates pass — no code change; gates last green — evidence: the 05:35 run

- [ ] Release-cycle deployment/acceptance: nothing deployed this cycle

- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
