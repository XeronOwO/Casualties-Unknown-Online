# 1.0 prosthetics: a teammate sees the owner's prosthetic limb (2026-11-10)

Batch `20261110-a`, the 1.0 release install (`0.1.0+19c6c7d8` with the acceptance channel) as
the host and a byte-copy of the install as the guest, both on IP direct (`127.0.0.1:7777`).
`launch-clients.ps1` is not used for the release install; the two instances are started
directly, the host creates the IP session and the guest joins it.

## The fixture

`tools/acceptance/recipes/limb-prosthetic4.cs` (`mode=set|read`):

- `mode=set limb=3 item=pegl` on the owner's client writes the native `Limb.ProstheticInfo`
  (the shape the game's save load writes, `SaveSystem.cs:305-307`) on the owner's own limb —
  the same state the wound view's release installs (`Item.cs:749-830`).
- `mode=read` lists every body in the scene with the limbs that carry a prosthetic.

## The reading

Owner (guest):

```
{"ok":true,"result":"set:True:pegl"}
```

Teammate (host), after the owner's next character report:

```
{"ok":true,"result":"Character_E94C1C2AD6140840[15]:3=pegl/False | Body[15]:-"}
```

- The owner's clone on the teammate's screen carries the prosthetic on the third limb
  (`3=pegl/False` — the limb is not dismembered, it is the reattached prosthetic limb).
- The teammate's own body shows none (`Body[15]:-`) — the block travels per limb, not per client.

## What the batch also proved (1.0)

- The remote body now renders: with the demo's `"Experiment"` template name gone in 1.0 the clone
  factory logged `"Experiment" player object not found` per frame and every teammate was invisible;
  the live player body is the template now (commit `19c6c7d8`). Before that fix the host's scene
  read one body (`Body[15]:-`); after it, two (`Character_…[15]` and `Body[15]`).

## Limits

- The fixture writes the state directly (the report is driven by the periodic character data), so
  the install's own action (the wound view's release with a peg limb item) is not staged here; the
  native call site is cited, and the wire/apply is what the rows judge.
- The prosthetic's colour channels are carried but no UI turns on them in this batch; the row
  covers the state and the identity of the limb, not a tint on the clone.
