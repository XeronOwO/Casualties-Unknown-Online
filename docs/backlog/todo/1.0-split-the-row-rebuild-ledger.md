# Split the row-rebuild ledger before it outgrows one page

- Status: Todo
- Priority: Low
- Owner: unassigned
- Created: 2026-11-23

## Design

The corpus this page belongs to is indexed in `docs/design/INDEX.md`, and the split keeps that index honest: each new
page is a domain page the index can point at, not a fragment of one.

`docs/backlog/in-progress/1.0-rebuild-each-acceptance-row-from-the-game.md` holds one fault sheet per acceptance row and
passed the 114688-byte document budget on 2026-11-23 (115122 bytes). The budget exists so a page stays readable in one
sitting; the ledger is now at the edge, and every further row pushes it over.

The split follows the domains the suite already uses: the world rows, the item rows, the medical rows, the session rows,
and the meta rows that measure our own surfaces. Each page keeps the same five-step shape, and the in-progress ticket
keeps the standing order plus an index of the pages.

## What changes

- One page per domain under `docs/backlog/in-progress/row-rebuild-<domain>.md`.
- The rebuild ticket keeps the method, the standing order and the page index.
- The census rows move with the pages; nothing is deleted, so the fault sheets stay whole.
