# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.
- [x] Design comprehension — a wait belongs in the client that owns the fact, not in a caller's sleep loop — evidence: the driver's new `wait-state` polls its own presence and answers `reached` + `waitedMs`
- [x] Native parity — reads `IWorldPresenceQuery` in the same process — evidence: the live answer `{"ok":"true","key":"inWorld","reached":"false","waitedMs":"1204"}`
- [x] Native parity probe — the action answers at the menu with reached=false and the full budget consumed — evidence: the same call
- [x] Entry mapping — the script's action set and switch carry `wait-state`; the driver dispatches it — evidence: the patched lines
- [x] Mechanism inventory — the command name, the argument (the key) and the text (the budget) are the whole contract — evidence: the driver block
- [x] Whole-family audit — `wait-log`, `log-tail` were already custom actions; they are now listed in the script's set too — evidence: the action set diff
- [x] Self-check table — two tooling files; no product code — evidence: `git status --porcelain`
- [x] Verification design — the suite's conversion to this action comes next; the action itself is proven by the live call — evidence: the answer above
- [x] Plan approved by the user — the goal's main line (event-driven) — evidence: the goal's 2026-11-14 paragraph
- [x] Structure review done — one action, one predicate, one answer shape — evidence: the diff
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: unchanged tooling; the suite build was green at 05:52 this run

- [ ] Release-cycle deployment/acceptance: nothing deployed this cycle

- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
