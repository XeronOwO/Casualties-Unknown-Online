# 贡献者文档

[文档总览](../README.md) > 贡献者文档

---

一个改动要被称作“做完”，先得满足 `docs/zh/contributing/` 里的这些东西：命令、门禁（gate）、仓库地图、页面规则，以及它必须经过的复核（review）。

1. [构建、测试与部署](build-and-test.md) —— 要跑哪些命令、哪一层测试最小又能抓到问题、出错时看哪个日志。
2. [门禁与绑定规则](gates-and-rules.md) —— 门禁工程是什么、它盯着哪些约定、新门禁怎么写。
3. [仓库地图与坑](repository-map-and-pitfalls.md) —— 一个文件该放哪个工程、谁能引用谁，以及这棵树里已知的陷阱。
4. [文档编写规范](documentation-standard.md) —— 两棵镜像树、页面形状，以及一对页面怎么保持同步。
5. [复核与交付](review-and-delivery.md) —— 从“想清楚”到“提交”的固定顺序、交付清单，以及提交信息约定。

两份登记表不放在这些页面里：[规则到门禁映射](../../evidence/normative-gates.md)回答“这条规则由哪个门禁盯着”，
[测试并行记录](../../evidence/test-parallelization.md)存放那些测出来的数字，本节刻意不复述它们。

这些页面写给贡献者；agent 必须遵守的绑定规则在仓库根目录的 [`AGENTS.md`](../../../AGENTS.md)。
