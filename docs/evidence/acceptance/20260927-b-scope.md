## Method

The batch was planned from a re-derivation over all 142 `review/` tickets, never from the earlier
triage reports (`.acceptance/triage-*`, whose headline counts disagreed with their own lists). Four
independent classifiers each emitted exactly one line per ticket — class, the decisive quote, and the
named evidence — against a written contract; the orchestrator then re-derived line counts, set
equality and class counts mechanically, and a second pass re-read every `offline` candidate in full
and grounded every acceptance row in this run's evidence. A candidate whose row could not be grounded,
or was only decided by a weaker check than the row states, was dropped and stays in `review/`. The
per-slug classification and the subagent reports are local run artifacts under the directory named by
`acceptance-artifacts-dir`.

## Fix round

The first move pass then turned the gate suite red on three checks: 45 prose references to the moved
tickets across 22 gated documents, five sibling relative links in `review/` tickets, and one test
anchor in a new record. The references were re-pointed — including the ones inside the moved tickets,
which the gates exempt, and the ticket-path comments in `src/`, `tests/` and the evidence JSON; the 11
tickets whose `- Acceptance record:` bullet had landed inside a multi-line header bullet were rebuilt
from their `review/` revision, and the gate suite went green again (288/288, `gates-after-moves.log`
and `gates-pre-review.log`). The independent adversarial review then read the frozen tree and its
findings were fixed in the same change; the review reports are local artifacts under the directory
named by `acceptance-artifacts-dir`.
