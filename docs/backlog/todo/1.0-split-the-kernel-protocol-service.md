# The kernel protocol service is over its line ceiling

- Status: Todo
- Priority: Low
- Opened: 2026-11-27
- Owner: session

## Why

`src/CasualtiesUnknownOnline.Application/Kernel/KernelProtocolService.cs` is 632 aggregate lines. Its design
budget is 600 and `docs/architecture-debt.json` records the 632 ceiling. The run-announcement work
(`d75c67c65`, `f99768ca8`) raised it from 620: the host barrier in `BroadcastCommittedBatch`, the
re-baseline flag threaded through `SendCheckpoint`, and the guest's quiet handling of a batch from a run it
was never announced.

## Design

This is an extraction, not a protocol change: read `docs/design/cross-cutting/saves-and-recovery.md` for the
run lifecycle the split must preserve, and `docs/architecture/current.md` for the kernel protocol's owners.

## Scope

Split by responsibility, not by line count: the guest-side receive path (committed batches, checkpoints,
commands and their replay windows) leaves `KernelProtocolService` as the host-side broadcast and journal
owner plus the composition point. No behaviour change; the existing suites are the guard.

## Done when

The class is at or under 600 aggregate lines, `docs/architecture-debt.json` no longer records it, and the
full suite and gates are green.
