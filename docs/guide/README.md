# Playing Casualties Unknown: Online

English | [中文](README.zh.md)

Casualties Unknown: Online (CUO) is a co-op multiplayer mod for *Casualties: Unknown* (Demo). One
player hosts the world, the others join it, and everyone plays the same run: the same map, the same
loot, the same deaths.

This guide is written for players. It explains what the mod does, how to start a session and what
you will notice while playing. It does not explain how the code works — that is the developer
guide's job.

## What a session looks like

The host runs the game as usual and opens the session from the CUO online panel. Guests join
through a Steam lobby, and a direct IP mode exists for players who cannot use Steam. Everything the
host's world does — the map, the items, the enemies — becomes the shared world.
