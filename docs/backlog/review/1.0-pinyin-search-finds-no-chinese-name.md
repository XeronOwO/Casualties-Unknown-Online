# The pinyin search filters but matches no Chinese recipe name

**Status:** Review — the host's own crafting panel, read on the 1.0 release: the search filters the
recipe list but the pinyin query finds nothing, so a Chinese client cannot search by pinyin. What is
missing is the mapping step inside the filter for this build of the game.

**Priority:** Medium (a Chinese client loses the pinyin way into the crafting list; the list itself
and the English search work).

## The reading (2026-11-13, the host on the release install, its UI in Chinese)

- `crafting-search query=flimsy` → `{"ok":true,"query":"flimsy","panelActive":true,
  "fieldText":"flimsy","rowCount":1}`; the plugin log carries `[Pinyin] recipe list filtered by
  'flimsy'.` then `[Pinyin] extended match: 'flimsy' matched 'flimsyknife'.`
- `crafting-search query=cuiruo` → `{"ok":true,"query":"cuiruo","panelActive":true,
  "fieldText":"cuiruo","rowCount":0}`; the plugin log carries `[Pinyin] recipe list filtered by
  'cuiruo'.` twice and no `extended match` line.

The plugin is installed and running (its log lines appear), the search reaches the game's own
recipe list, and the field text lands in the panel; only the pinyin-to-name matching produces no row.
The panel itself shows Chinese names (the crafting panel showed the fragile knife row in the same
session).

## What the row needs

1. Read the plugin's own matching path for this game build: which name it compares the pinyin
   candidate against (the recipe's display name vs the item's localized name), and whether the
   Chinese name is present at that point (the game may load the English name into the recipe object
   and localize only at the panel).
2. A fix in the plugin (a mapping loaded from the game's own localization) or, if the name is not
   reachable, the row is a product limit to record on the plugin's page.

The suite's crafting row (`crafting`) covers the crafting entry itself and passes; this pinyin row
stays parked on the sweep ticket (`docs/backlog/in-progress/1.0-regression-sweep.md`) until the
mapping is readable.
