# 做一件事

[文档总览](../README.md) > 做一件事

---

一件事一页，都在 `docs/zh/how-to/`：你想做什么、步骤、能跑的例子、常见坑，以及怎么验证真的成了。每一页都假设你读过[你的第一个模组](../start/your-first-mod.md)。

- [给其他玩家发消息](send-a-network-message.md) —— 模组网络：谁能发什么，以及消息没送到时会怎样。
- [声明权限与主机命令](declare-permissions-and-commands.md) —— 八个标志，以及一条在主机上执行的命令。
- [在界面里加一个面板](add-a-ui-panel.md) —— 一个本身改变不了任何东西的本地窗口。
- [读取游戏状态](read-game-state.md) —— CUO 已经掌握的另一名玩家的状态，以及这份读数有多新。
- [注册内容](register-content.md) —— 物品、配方、地块：世界会当作自己一部分的内容。
- [让模组数据跨会话保留](save-mod-data-across-sessions.md) —— 模组自己的小表，由主机写入，下次开局读回。
- [判断一个动作由哪一侧判定](decide-which-side-judges-an-action.md) —— 谁的客户端判定，主机又留着什么。

这些页面背后的精确契约在[参考](../reference/README.md)，设计原因在[弄懂原理](../internals/README.md)。
