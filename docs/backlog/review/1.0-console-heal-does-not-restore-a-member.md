# 1.0: the host's `/heal @a` leaves the member's body unchanged

## What the player sees

The host runs `/heal @a`. The console answers that the reset was relayed to the target's own
client. The member's limb stays as it was — no error reaches either player's screen.

## The reading (2026-11-12, release build, two clients over IP direct)

- The suite's `console-heal` case (`tests/CasualtiesUnknownOnline.AcceptanceSuite/Cases/ConsoleHealCase.cs`)
  wounds the member's limb 0 first (`wound-seed limb=0 force=300`), then the host runs
  `/heal @a` through the driver's console action.
- Host answer: `{"ok":true,"command":"console","applied":true,"lastLine":"reset 12194594544082510599:
  the command was sent to that client, which runs the full reset and answers with its state."}` (translated).
- The member's own client, polled for 15 s: `{"ok":true,"source":"local","limb":0,"skinHealth":0.309,
  "bleedAmount":0,"pain":85.016,"muscleHealth":6.538,"shrapnel":0,"dislocated":true,"dismembered":false,
  "isHead":true,"infected":false,"broken":false}` — unchanged.
- The same case passed in earlier runs on the same fixture (the host's own body is the one the
  console resets; a member is the new target).

## What has to be found

1. What the member's client receives for the relayed reset (its own log: the request line and the
   body it applies to), and whether the execution path resolves the member's body or the host's.
2. Whether the reset is executed only for the client that owns the body, and if the member's
   ownership is current.
3. Whether the answer "applied" is the relay's acceptance rather than the reset's completion.

## Design

The body-verb service and its relay are described by
[docs/design/cross-cutting/saves-and-recovery.md](../../design/cross-cutting/saves-and-recovery.md)
and [docs/design/game/README.md](../../design/game/README.md): the host owns the verb, the
target's own client executes the reset on its body.

## Acceptance

1. On a two-client session the host runs `/heal @a` against a wounded member; the member's own
   client reads the limb restored within the poll window.
2. The same for `/kill @a` (the shared service's other verb).
3. The judge is a reading on the target's client, not the console's answer.
