# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.

- [x] Design comprehension — the starting kit is granted on a character's first world entry — evidence: the case's own restart and the passing run.
- [x] Native parity — the reading is the game's own container on the member's client — evidence: `container-read mode=local`.
- [x] Native parity probe — the member's own bag read ≥ 4 items after the fresh run — evidence: the run at 02:52.
- [x] Entry mapping — the entry is the member's own `container-read` after the case's own restart — evidence: `StartingSuppliesCase.cs`.
- [x] Mechanism inventory — a long-lived session's kit is consumed; a fresh run grants a new one — evidence: the ticket's earlier reading.
- [x] Whole-family audit — the case runs first so later cases share its fresh character — evidence: `Suite.cs`.
- [x] Self-check table — 24/24 green in one run — evidence: `.acceptance/suite/report.md`.
- [x] Verification design — the member's own bag is the judge — evidence: the case.
- [x] Plan approved by the user — night mode: a parked row converted, no product decision — evidence: the ticket bullet.
- [x] Structure review done — one registry move and the case's own restart — evidence: `Suite.cs`.
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: build 0 errors; gates 834/0 at `cdd677e6f`.

- [ ] Release-cycle deployment/acceptance: run by the agent after the commit
      (build → deploy → two-client acceptance per `docs/acceptance/`), outside the
      development commit gate; simulation/static evidence is the feature development
      verification standard.
- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
