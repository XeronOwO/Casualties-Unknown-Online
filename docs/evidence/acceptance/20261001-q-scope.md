- **Run D** covers the rows the `20261001-m` plan assigned to it but which never ran (the batch closed

- **Run E** covers the two S3.6 rows that need a live session (its batch-m plan left row 3 "shared with

## The evidence channel (declared before the run)

- **machine**: each client's own CUO rolling log (`BepInEx/logs/latest.log`, rotated per start), the
  probe JSON written into the batch directory under `acceptance-artifacts-dir`, the world archive on
  the save root (`live/`, `backups/*.cuoz`), and this run's own build/suite outputs.
- **frame**: one window-level capture per visual row (never the desktop), read by the agent and cited
  by artifact id.
- **residual**: a judgement that is genuinely a person's (the end screen's clock text when the panel
  cannot be driven; a "looks right" visual half).
- `Logging.MinimumLevel` is set to `Debug` on every client through the same editor the Preferences
  control writes and restored to `Information` before the clients close; every probe a record cites is
  written into the batch directory as its own file.
- A row this run cannot put the world into is `unproven` with the missing setup named; a row only a
  person can judge is a residual, never a self-issued pass.

## Limits (declared before the run)

- **A single run does not disprove a rare loss.** The repeated-cycle rows record how many iterations
  ran; the clock comparison records its observation window.
- **Substitutions are named.** Debug-entry setups (`spawn`/`explode`/`floodfill`/`locate`/`skiplayer`
  through the game's own registered command), the forced layer timer, the renamed saves root and the
  in-process leaves/clicks are each recorded in the row's own limits.
- **Unreachable setups stay open.** A row whose setup the run cannot reach is `unproven` with the gap
  named; its ticket stays in `review/`, never closed on a guess.
- **The gate stays the deployed artifact.** Every run judges only rows produced after its own build,
  deploy and identity check; an earlier suite result is never this batch's evidence.
