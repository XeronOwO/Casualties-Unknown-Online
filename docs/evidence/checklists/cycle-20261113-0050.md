# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.

- [x] Design comprehension — a reading recorded against the plugin's own matching path; no design changed
  — evidence: the pinyin ticket's `## What the row needs` names the mapping step to read next.
- [x] Native parity — no native behaviour changed; the reading is the game's own panel filter
  — evidence: `crafting-search` reads the game's own recipe list (`rowCount` 1 vs 0).
- [x] Native parity probe — the panel was driven through the game's own search field
  — evidence: `panelActive true, fieldText 'cuiruo'` with the plugin's own filter line in its log.
- [x] Entry mapping — the entry is the crafting panel's search field, read through `crafting-search` — evidence: the crafting panel's search field, read through `crafting-search`
- [x] Mechanism inventory — the plugin's filter path, the panel's field, and the log lines are named on the ticket — evidence: the plugin's filter, the panel field and the log lines are named on the ticket
- [x] Whole-family audit — the English branch (`flimsy`) and the pinyin branch (`cuiruo`) were both read — evidence: the English branch and the pinyin branch were both read
- [x] Self-check table — the ticket records both readings and the plugin's own log lines — evidence: the ticket records both readings and the plugin's log lines
- [x] Verification design — one recipe call per branch, judged on `rowCount` — evidence: one recipe call per branch, judged on `rowCount`
- [x] Plan approved by the user — night mode: the finding is filed with its options, no product decision asked — evidence: night mode: the finding is filed with options, no product decision asked
- [x] Structure review done — no code changed; the ticket names the plugin's matching path as the next read — evidence: no code changed; the ticket names the plugin's matching path
- [x] Build + dotnet format + dotnet test normative gates pass — documentation-only cycle; the previous cycle's gates read 834/0 at `11b12e8f5` — evidence: documentation-only cycle; the previous cycle read 834/0 at `11b12e8f5`

- [ ] Release-cycle deployment/acceptance: run by the agent after the commit
      (build → deploy → two-client acceptance per `docs/acceptance/`), outside the
      development commit gate; simulation/static evidence is the feature development
      verification standard.
- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
