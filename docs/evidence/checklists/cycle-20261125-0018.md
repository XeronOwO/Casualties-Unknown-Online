# Delivery checklist

Fill every box, then run `tools/check-delivery.ps1`. Each box needs the literal ` — evidence: ` followed by the evidence.

- [x] Design comprehension — evidence: the ticket's "The one run, and what it still inherits" section states the claim (every row passes in one order) and the four measured carriers of the order failures.
- [x] Native parity — evidence: the runner uses the game's own entries for the fresh run (`StartFreshRunAsync` leaves the world and starts a new one through the host's own menu), and no game rule is re-implemented.
- [x] Native parity probe — evidence: `.acceptance/all-3`: 51 of 66 rows pass in one run, and three rows that failed in the previous run (`block-sync`, `net-conditions`, `host-rule-toggles`) pass in a five-row order probe once the fresh-run rule is on.
- [x] Entry mapping — evidence: `AcceptanceCase.LeavesTheRunChanged` lists the rows that continue a save, restart the host, end the run or descend a layer; the runner reads it after each row and starts a fresh run before the next.
- [x] Mechanism inventory — evidence: `Suite.RunAsync` takes the flag, `Suite` keeps it in `runChangedByTheLastRow`, and `SessionDriver.StartFreshRunAsync` performs the game's own leave-and-restart.
- [x] Whole-family audit — evidence: the four carriers named in the ticket cover every remaining red that passed alone; a fifth attempt (healing both bodies before every row) was measured to make six green rows fail, so it was reverted rather than kept.
- [x] Self-check table — evidence: the ticket names, per carrier, the row, its reading and the state it does not get.
- [x] Verification design — evidence: the row failure messages carry both sides — the trader's credit and the item's contents, the census totals on both clients, the clone's position before and after the walk.
- [x] Plan approved by the user — evidence: the standing order is to make the one run cover every row and pass.
- [x] Structure review done — evidence: the freshness knowledge stays in one place (the runner), not in each row; the driver's unused heal helper remains available but is not called.
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: units 6761/6761, gates 837/837, `dotnet format --verify-no-changes` exit 0.
- [x] Release-cycle deployment/acceptance — evidence: tests-only change, nothing to deploy; `.acceptance/all-3` is the acceptance reading.
