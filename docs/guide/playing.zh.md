# 会话中的游玩

[English](playing.md) | 中文

客机玩的是同一个游戏、同一套规则;区别在于判定发生在哪里。你的机器会立刻执行你的操作并把结果
报告出去,而主机先接受这份报告,除非它明显与其他人的操作冲突。

本页描述客机在一次正常会话中会看到什么。它从玩家的角度写作;「设计说明」解释了这些接缝为什么
落在现在的位置。

## 你会注意到的

- 其他玩家的角色会在你的世界里移动、背负、坠落和死亡,模组会标明谁是谁。
- 你拾取、丢弃、烹饪或使用的物品对所有人共享;另一名玩家打开的容器,对你俩显示同样的内容。
- 屏幕边缘的箭头会指向视野之外的队友。
- CUO 交互面板(交互键可配置,默认 `F6`)显示会话的当前状态。

## 发生得很快的操作

射击、命中以及快速拾取会在它们发生的机器上立刻结算,之后再报告给主机。主机先接受报告,只有当
冲突明显时才纠正,例如两名玩家在同一瞬间争抢同一件物品;争抢失败的一方会被告知原因,而不是被
悄悄吞掉这次操作。

## 当看起来不对劲时

如果你的角色或物品被拉回原位,说明主机那一份与你的报告不一致。这是有意为之:共享世界保持一致,
而纠正是可见的,而不是双方在无人知情的情况下各自漂移。如果反复出现拉回,请连同日志一起反馈。
