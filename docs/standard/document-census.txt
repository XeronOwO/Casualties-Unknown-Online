#
#   <path> | <disposition> | <reader> | <reach>
#
# disposition  keep    the document stays, and `reader` names who opens it
#              rework  the shape is the defect (an append-only log); `reach` names the ticket carrying the work
#              delete  nothing reaches it 鈥?no citation, no index row; `reach` names the ticket removing it
# reader       loaded       the loader injects it at the point of work (root and nested AGENTS.md, CLAUDE.md)
#              index        a reader arrives from a section index; `reach` is that index page
#              spec         an agent opens it while working in the area; `reach` is the page that routes to it
#              claim        an agent auditing a claim follows a citation; `reach` is the citing document
#              attribution  someone asks why the system is like this; `reach` is the backlog index
#              none         nothing reaches it (rework and delete rows only)
# reach        `-` only for an entry point a reader opens directly: a file the loader injects, or an area's own
#              index. Every other row names a document that references this one, and DocumentCensusGateTests
#              fails when the named document does not name it back.
