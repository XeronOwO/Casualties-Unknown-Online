# Phase 5 tooling and ecosystem

- Status: Future
- Priority: Low
- Category: Future / tooling / ecosystem

Mod manager, auto-install, crash reports, network diagnostics, compatibility database, dedicated
server only if public hosting becomes relevant.

The 2026-09-20 review added the developer-experience half of the same phase (a Forge/Fabric-style
ecosystem is a toolchain, not only an API): a Mod SDK/template, a mod unit-test host that runs
without the game assemblies, a manifest/API analyzer, a content-definition validator, multi-mod
dependency-resolution tooling, generated public API documentation, and packaging/install/conflict
diagnostics. None of it has a trigger yet — the first third-party mod is the trigger for most of it —
so it stays here as a memo rather than becoming work.
