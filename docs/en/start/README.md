The first-run line, in `docs/en/start/`: read it in order — every page ends with something you can
watch working. It assumes no knowledge of CUO and none of the game's internals.

1. [What CUO is](what-is-cuo.md) — the mod, a session, and what it deliberately leaves out.
2. [Install and play](install-and-play.md) — install it, host a session, join one, and the three
   failures you are most likely to hit.
3. [Set up a development environment](set-up-dev-environment.md) — get the checkout, build it, run the
   tests, and deploy it into your own game.
4. [Your first mod](your-first-mod.md) — the two files a CUO mod needs, what the framework hands you,
   and how to watch it work.

Depth boundary: this line only goes as far as "you can use it". How each mechanism works is in
[Internals](../internals/README.md); the exact contracts are in `../reference/`.
