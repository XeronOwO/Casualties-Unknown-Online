- [ ] Whole-family audit — every seam returns the untouched path unless `CUO_ACCEPTANCE_RED` names its case; seven earlier C3 seams are recorded on the ticket and the run that left the row green is what named the arrival's real path (the item-state load into the proxy, not the clone render)

- [ ] Verification design — build, units, gates, format, deploy `-Acceptance`, red run, green rerun
- [ ] Plan approved by the user — the night-mode goal authorises self-chosen ticket work without asking
