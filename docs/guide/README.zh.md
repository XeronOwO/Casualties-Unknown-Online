# 游玩 Casualties Unknown: Online

[English](README.md) | 中文

Casualties Unknown: Online(CUO)是《Casualties: Unknown》(Demo)的多人合作模组。一名玩家作为主机(host)
运行世界,其他人加入进来,所有人在同一局里游玩:同一张地图、同一批战利品、同样的死亡。

本指南写给玩家。它说明这个模组做了什么、如何开始一次会话(session),以及游玩时你会注意到什么。
它不解释代码如何工作 —— 那是开发者指南的任务。

## 一次会话是什么样子

主机照常运行游戏,并从 CUO 的联机面板开启会话。客机(guest)通过 Steam 大厅(lobby)加入;无法使用
Steam 的玩家还有直连 IP 模式。主机世界中的一切 —— 地图、物品、敌人 —— 都会成为共享世界。
