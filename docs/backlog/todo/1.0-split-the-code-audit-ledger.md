# Split the code audit ledger

- Status: Todo (2026-11-22) — the ledger is over the document budget and is queued for rework, not for reading
- Priority: Low
- Created: 2026-11-22

## Why

`docs/design/audit/code.md` is 122,368 bytes, over the 114,688-byte document budget the census gate enforces. It is a
single ledger that walks every corpus page against the code in both directions, so it grows with the corpus and has no
natural end. A page that size is not read; it is searched.

## What changes

- Split by area rather than by date: one page per `docs/design/` section (mechanics, items, surfaces, game, cross-cutting,
  audit), each carrying its own rows, and `code.md` becomes the index that names them.
- Keep the row format and the evidence column verbatim; the split must not rewrite a verdict.
- Update `docs/standard/document-census.txt` and `docs/design/INDEX.md` in the same commit, and re-run the census gate.

## Design

The corpus splits by reader, not chronology: an agent working on medical mechanics opens the mechanics ledger, not the
whole corpus' history. The index page keeps the "what this ledger answers" paragraph that `code.md` already carries.
