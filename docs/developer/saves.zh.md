# 存档

[English](saves.md) | 中文

CUO 保有自己的世界归档,从不读取或写入游戏自带的存档文件。一个世界就是一个文件夹归档,里面保存
当前状态和一串压缩备份 —— 这正是无需任何外部工具就能恢复、检查或修复它的原因。

主机是唯一的写入者。客机只保存自己的本地设置,别的什么都不存,所以某人的磁盘上永远不会出现第二份
分叉的世界状态。

## 布局

- `index.json` 列出所有世界,每个世界一个文件夹,里面有 `world.json` 与保存当前状态的 `live/` 目录。
- `live/` 保持未打包:保存就是一次快速的文件写入,人也可以直接阅读或修复它。
- `backups/` 保存压缩的 `.cuoz` 归档:层末切片、局中切片与自动切片。
- `world.lease` 指明当前正在写入这个世界的是哪个进程,所以两个实例无法交错写入。
- 被拒绝的快照会作为 `damaged-<stamp>/` 证据保留下来,而不是被删除。

## 写入什么

每个切片按域保存权威状态:局、玩家、物品、世界实体、敌人、流体、方块、瞬态,以及每个角色的数据。
新增一个域就是在归档里新增一个文件;它从不重写已有的数据块。

## 恢复

恢复一个世界会加载选中的切片,并重建它所描述的状态;被提升的备份以同样的方式加载。归档是带版本的,
所以由不兼容构建写出的切片会被带理由地拒绝,而不是被加载进一个它并不匹配的世界。
