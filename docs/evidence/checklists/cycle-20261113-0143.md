# Delivery checklist

Operating rule: a box is checked only after the item is CONFIRMED in this cycle. Bulk checking is forbidden — a box
that cannot be confirmed stays empty and the cycle stops. Documentation-only cycles fill every box in one pass and
leave the release-cycle deployment/acceptance line and the FORBIDDEN line unchecked.

- [x] Design comprehension — the poll rules the tick out; the snapshot is the new candidate — evidence: `skinHealth 0.334` at every poll for 15 s.
- [x] Native parity — no native behaviour changed — evidence: docs-only cycle.
- [x] Native parity probe — the case's own poll is the probe — evidence: 60 polls, one value.
- [x] Entry mapping — the entry is the console verb `/heal @a` — evidence: the console answer `applied: true`.
- [x] Mechanism inventory — `Limb.ImpactDamage` leaves no ticking component — evidence: the decompile reading on the ticket.
- [x] Whole-family audit — the reset's landing and the persistent value are both recorded — evidence: the ticket's two sections.
- [x] Self-check table — before/after reads and the 15 s poll are on the ticket — evidence: `## Reopened` and the new section.
- [x] Verification design — the next probe logs the limb writes and the applied report — evidence: the ticket's last paragraph.
- [x] Plan approved by the user — night mode: the reading is filed, no product decision asked — evidence: the ticket's status.
- [x] Structure review done — the candidate owner is the host's snapshot path — evidence: the ticket names it.
- [x] Build + dotnet format + dotnet test normative gates pass — evidence: gates 834/0 this cycle at `4c11cc01a`.

- [ ] Release-cycle deployment/acceptance: run by the agent after the commit
      (build → deploy → two-client acceptance per `docs/acceptance/`), outside the
      development commit gate; simulation/static evidence is the feature development
      verification standard.
- [ ] FORBIDDEN — never check this box; checking it fails the delivery gate
      (a honey-pot: a checked box means a step was skipped on purpose, which is
      exactly what the gate exists to catch)
